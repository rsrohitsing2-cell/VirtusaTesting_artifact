# TestNG Selenium Project

This is a Maven-based Java test project configured with TestNG and Selenium WebDriver.

## Requirements

- Java 17 or newer
- Maven 3.8 or newer

## Run the tests

```bash
mvn test
```

The project uses `testng.xml` as the TestNG suite file. Selenium Manager, included with Selenium 4, can automatically manage browser drivers when browser-based tests are added.
